# accessibility-review

Structured accessibility (a11y) review workflow targeting WCAG 2.1 AA compliance.

## What It Covers

- **Quick checklist** -- top-level WCAG 2.1 AA pass/fail checks
- **Semantic HTML audit** -- landmarks, heading hierarchy, alt text, native elements
- **Interactive elements** -- focus indicators, ARIA attributes, role assignments
- **Color contrast** -- 4.5:1 text, 3:1 large text, UI components at 3:1
- **Keyboard navigation** -- tab order, focus traps, skip links, shortcut conflicts
- **Screen reader testing** -- what to verify, common issues, ARIA live regions
- **Form accessibility** -- labels, error messages, required fields, autocomplete
- **Anti-patterns** -- common mistakes with specific fixes

## Severity Ratings

- **P0**: Blocks access entirely
- **P1**: Significant barrier to task completion
- **P2**: Minor inconvenience, still usable

## When to Use

Invoke this skill when reviewing UI code for accessibility, auditing an existing interface, or planning accessible component architecture.
