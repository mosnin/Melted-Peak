# Melted Peak Skill Catalog

Quick reference for all available skills. Find the right skill for your task.

## By Work Phase

### Starting a Project
| Skill | When to Use |
|-------|------------|
| **project-kickoff** | New project: interview → PRD → seed memory |
| **codebase-onboarding** | Existing project: learn the codebase systematically |
| **estimation** | Assess task complexity and scope |

### Planning & Architecture
| Skill | When to Use |
|-------|------------|
| **data-modeling** | Design entities, relationships, indexes |
| **api-design** | Design API contracts, endpoints, versioning |
| **state-management** | Choose state strategy for frontend |
| **error-handling-design** | Design error paths before building |
| **environment-config** | Plan env vars, secrets, feature flags |

### Building
| Skill | When to Use |
|-------|------------|
| **code-generation** | Scaffold new files following conventions |
| **git-workflow** | Branch, commit, and PR discipline |
| **testing-strategy** | What to test, which test type, how to structure |

### Reviewing & Verifying
| Skill | When to Use |
|-------|------------|
| **code-review** | Review changes for correctness, safety, consistency |
| **accessibility-review** | WCAG 2.1 AA compliance check |
| **security-audit** | OWASP, secrets, auth, data protection |

### Fixing & Maintaining
| Skill | When to Use |
|-------|------------|
| **debugging** | Systematic bug diagnosis and fix |
| **refactoring** | Safe incremental code restructuring |
| **performance-analysis** | Profile, find bottleneck, measure fix |
| **dependency-update** | Safely update a single dependency |
| **dependency-audit** | Full audit: vulnerabilities, licenses, freshness |
| **technical-debt-assessment** | Identify, classify, and prioritize tech debt |

### Deploying & Operating
| Skill | When to Use |
|-------|------------|
| **deployment-workflow** | Ship to production safely |
| **incident-response** | Handle production incidents |
| **documentation-generation** | README, API docs, ADRs, changelogs |

### System & Meta
| Skill | When to Use |
|-------|------------|
| **context-boot** | Boot Melted Peak at session start |
| **skill-router** | Create new project-specific skills |
| **retrospective** | Post-completion analysis, feed lessons back |
| **peak-manager** | Import, mount, unmount domain peaks |
