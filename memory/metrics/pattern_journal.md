# Pattern Journal

Running log of workflow patterns noticed during work. This is the "pre-skill" incubator -- patterns are logged here as they're observed, and when a pattern reaches 3 occurrences, the skill router is triggered to formalize it into a skill.

## How to Use

During normal work, when you notice you're doing something that could be repeatable:
1. Log it below with a tally mark
2. When it reaches 3 marks, flag it for the skill router
