# Debugging Patterns -- Summary

Reference material for diagnosing bugs: common error patterns organized by category (database, API, frontend, auth, build/deploy) and 7 systematic debugging techniques.

## When to Load
- During bug-fix work (alongside the debugging skill)
- When encountering an unfamiliar error pattern
- When stuck and need a different debugging approach

## Contents
- **common_errors.md**: Error pattern tables for database, API, frontend, auth, and build/deploy errors. Each with likely cause and investigation approach. Includes a debugging decision tree.
- **debugging_techniques.md**: 7 techniques -- binary search, rubber duck, minimal reproduction, data tracing, hypothesis testing, diff debugging, print debugging. Each with when-to-use guidance.

## Context Cost
Small -- quick-reference tables and technique summaries.
