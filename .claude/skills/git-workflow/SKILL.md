# Git Workflow

**Branch naming:** `[type]/[short-description]` (feat/, fix/, refactor/, docs/, test/, chore/)

**Commit format:** `[type]: [what changed and why]`

**Before committing:** run validation plan, check regression checklist, verify no .env files staged.

See `skills/git-workflow/source/SKILL.md` for full workflow.
