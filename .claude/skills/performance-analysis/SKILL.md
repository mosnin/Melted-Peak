# Performance Analysis

**Process:** Measure baseline → Profile (don't guess) → Hypothesis → ONE change → Measure again → Compare

**Never:** optimize without measuring, change multiple things at once, optimize code because it "looks slow."

See `skills/performance-analysis/source/SKILL.md` for full workflow.
