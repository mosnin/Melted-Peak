# Rules for Active State Files

- Always update `active/active_context.md` after completing each logical step
- Never delete active state files -- overwrite with current state or reset to stub
- Follow the templates in `docs/templates/` for file structure
- Update the Confidence Map when making assumptions
- The active issue's `## Attempted Solutions` section MUST be updated BEFORE trying any new approach
- Only one active issue at a time -- discovered issues go to `memory/known_issues.md`
