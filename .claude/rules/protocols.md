# Rules for Core Protocols

- Protocol changes require user confirmation before implementation
- Always update `docs/core/99_protocol_cheatsheet.md` when adding or modifying protocols
- Keep protocols under 150 lines where possible
- All protocols must be referenced in at least one context compiler profile
- Use the established numbering ranges: 00-03 foundation, 04-09 operations, 10-16 engineering, 17-21 integration, 23-25 quality, 99 cheatsheet
- Gaps in numbering are intentional -- leave room for future additions
